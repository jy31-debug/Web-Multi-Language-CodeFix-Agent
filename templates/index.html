Web Multi-Language CodeFix Agent

上传单个代码文件或 zip 项目压缩包，输入一句自然语言需求，Agent 会自动识别语言、选择修复路线、调用 LLM 生成修复代码、Diff 和报告。

提交修复任务

支持两种上传方式：
1. 单个代码文件：例如 buggy_add.py、Main.java、main.c
2. 项目压缩包：例如 project.zip，里面可以包含多个源代码文件
测试命令怎么填？
不懂可以留空，Agent 会走静态项目修复路线。
Python 项目常用：pytest
Java Maven 项目常用：mvn test
Java 单文件常用：javac Main.java
C 项目常用：gcc main.c -o main.exe
JavaScript 项目常用：npm test 或 node main.js

Agent 路线

路线 1：单文件修复

  • 上传一个代码文件
  • 测试命令留空
  • 走 SingleFileFixSkill

路线 2：测试驱动项目修复

  • 上传 zip 项目
  • 填写测试命令，例如 pytest
  • 走 PythonTestFixSkill

路线 3：无测试脚本项目修复

  • 上传 zip 项目
  • 测试命令留空
  • 走 ProjectStaticFixSkill
  • 多个修复文件会打包成 zip 下载
